# Original lesson videos

Original Signal Lab illustrated lessons with conversational AI neural narration. Each lesson runs approximately 5-7 minutes and has twelve chapters, a poster, and English WebVTT captions. No external creator footage or IXL artwork is included.

Regenerate with python scripts/expand-video-scripts.py and python scripts/render-full-lessons.py after installing the optional rendering tools documented in PORTAL.md. Voice generation requires an internet connection and sends public lesson narration to Microsoft's speech service; playback uses only the generated site assets. Sentence captions use estimated timings within accurately timed chapters. Narration is AI-generated, not human-recorded.
